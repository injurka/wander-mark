# Архитектура Монорепозитория (Bun Workspaces)

Этот проект — монорепозиторий. Код разделен на независимые пакеты в папке `apps/`. 
Ты ОБЯЗАТЕЛЬНО должен учитывать контекст пакета, в котором редактируешь файл. Смешивание сред ЗАПРЕЩЕНО.

## Пакеты (Workspaces)

### 1. `apps/client` (Frontend / PWA)
- **Стек:** Vue 3 (Composition API), Vite, PWA.
- **Среда:** Браузер.
- **Правило:** Здесь ЗАПРЕЩЕНО использовать Bun API (например, `Bun.serve`, `Bun.file`), обращаться к базе данных напрямую или использовать пакеты Node.js (fs, path).

### 2. `apps/server` (Backend)
- **Стек:** Bun, TypeScript.
- **Среда:** Сервер (Bun runtime).
- **Правило:** Здесь НЕТ браузерных API (`window`, `document`, `localStorage`). Вся работа с файловой системой и сетью должна использовать нативные API Bun, где это возможно. Никакого Vue/UI кода.

### 3. `apps/plugin-*` (Плагины)
- **Примеры:** `plugin-ai-assistant`, `plugin-chinese-tooltip`, `plugin-hanzi-saver`, `plugin-reading-tracker`, `plugin-recipe-viewer`, `plugin-russian-tooltip`, `plugin-smart-textbook`.
- **Назначение:** Расширения функционала (для клиента или сервера).

### 4. `apps/cli` (Инструменты командной строки)
- **Назначение:** Различные скрипты и CLI-утилиты для проекта.

# Обязательные действия

1. Перед завершением работы и написанием ответа ВСЕГДА проверяй код линтером: `bun run lint`.
2. После этого ВСЕГДА запускай проверку типов: `bun run typecheck`.
3. Если есть ошибки типов или линтера — исправь их самостоятельно.
