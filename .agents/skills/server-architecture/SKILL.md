# Архитектура Backend (Server)

## Работа с Базой Данных (bun:sqlite)
1. **Схема:** Мы используем встроенный `bun:sqlite` без ORM (таких как Drizzle). Вся структура БД инициализируется в `apps/server/src/db/index.ts`. Если тебе нужно написать новый запрос или создать таблицу, СНАЧАЛА посмотри этот файл.
2. **Анализ данных (MCP):** Если тебе нужно понять, какие реально данные лежат в базе, используй MCP-инструмент `sqlite-main-db`, чтобы сделать `SELECT`. 
3. **Запросы:** Мы пишем обычные SQL запросы через методы `bun:sqlite` (`db.query()`, `db.run()`, и т.д.).

## Инструменты и Среда (Bun)
- Сервер работает на Bun. ЗАПРЕЩЕНО использовать стандартные модули Node.js, если есть нативные, более быстрые аналоги Bun (например, используй `Bun.serve`, `Bun.file`, `Bun.password`).
- ЗАПРЕЩЕНО использовать MCP-инструменты `vue-docs`, так как они относятся только к фронтенду.
- Если ты сомневаешься в синтаксисе API Bun, **НЕ ГАДАЙ!**
  1. Используй встроенные инструменты поиска или ищи ответы в официальной документации через интернет.
  2. Также всегда проверяй типы прямо в коде (например, наведя курсор или заглянув в определения TypeScript).
